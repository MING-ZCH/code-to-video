# Case B: the bench meme (瘫坐长椅原子弹爆炸) as a six-style shader remix

**Input:** `tests/inputs/bench-meme.md`, a written description of the meme. The meme image and the 42 s reference video are Feishu attachments that couldn't be downloaded in the VM. When the image is added, `node bin/c2v.mjs ingest bench <image>` supplies its palette and composition; the scene needs no other change.
**Output:** `projects/bench/` (STORYBOARD.md, scenes/main.js), `out/video.mp4` (24 s, 1920×1080, scale 1), `out/synth.wav`.

## What the design document asked for, and how it's met

| design doc (Feishu) | here |
|---|---|
| a meme turned into animation, all picture and sound generated by code | one painted world, the blast drawn by shader generators (`explosion`, `shockwave`), the soundtrack synthesised from a 63-event score (`engine/audio.js`) |
| one shader per style | six segments: cave → inkwash → stained → halftone → pixel → blueprint (`stylize()`), one shader each |
| the same image across many styles/media | same composition and the same moment in every segment; the camera framing changes per segment |

## Process (c2v skills)

- **Storyboard.** Six 4 s segments (2 bars at 120 BPM). Each opens on the blast's flash (a flash cut that sets the joke's rhythm) and has one small Clawd action. A running beanie prop gives continuity, and the payoff is the shades.
- **Check.** 0 errors, 0 warnings.
- **Review.** 4 passes found 6 problems, all fixed:
  - The bench backrest crossed Clawd's head, so Clawd looked caged. Fix: a lower backrest.
  - Medium shots cut the blast off. Fix: re-framed.
  - Stained-glass cells broke Clawd apart. Fix: the shader got a cell-size parameter (`u.r`).
  - Props were on the far arm, hidden behind the body in the flipped ¾ view. Fix: moved to the near arm and enlarged.
  - The sip didn't read through stained glass. Fix: swapped actions with the halftone segment.
  - The hat flew off 0.45 s before the shockwave arrived (effect before cause). Fix: tied to the wave constant.
- **Medium choice.** The base is `flat` on purpose. Every frame is restyled by a full-frame shader that replaces watercolour texture anyway, so the full-scale final costs about 1 s/frame on the VM instead of 13–25 s.
- **Determinism.** Selftest passed at scale 1. Rendered 576 frames at scale 1, then synth + encode.

## Measured

- **Audio sync.** Booms at 4.02 / 8.02 / 12.00 / 16.02 / 20.02 s, on every flash. Phone clicks at 17.2 / 18.6 s and the shades chime at 22.2 s, exactly the scene constants. Peak 0.71, no clipping.
- **Video metrics.** 6 cuts (the flash cuts), median shot 4.0 s, near-still 0%.
- **Metric caveat.** `bottom_band_text` = 0.33 although there is no text. The halftone and pixel textures trigger the subtitle detector, so it needs a texture guard before it can be used on stylised renders.
